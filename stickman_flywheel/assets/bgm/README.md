# assets/bgm — 자체 음원(BGM)

쇼츠에 섞을 **직접 제작했거나 권리를 가진 음원**을 이 폴더에 넣으세요 (mp3 · wav · m4a).

- 대시보드 사이드바 **🔊 오디오 및 성우 제어 → 🎵 자체 BGM 넣기**에서 파일 하나를 고르거나 "랜덤"을 선택합니다.
- 나레이션이 나오는 동안은 BGM이 20%(약 -14dB)로 내려가고, 영상 시작은 페이드인·끝(엔딩 카드)은 페이드아웃됩니다.
- 음원마다 평균 음량을 한 번 재서(`.bgmlevel.json` 캐시) 나레이션보다 조금 낮은 레벨로 자동 보정합니다.
- git에는 배포용 **mp3만** 올라갑니다 (wav 원본은 용량 때문에 제외). 같은 이름의 wav·mp3가 같이 있으면 한 곡으로 보고 wav를 씁니다.

DistroKid 등으로 YouTube Content ID에 등록한 곡이면, 내 채널 영상에도 저작권 주장(Claim)이 붙을 수 있습니다.
배급사 대시보드에 업로드할 채널을 예외(화이트리스트)로 등록하는 기능이 있는지 확인해 두세요.
